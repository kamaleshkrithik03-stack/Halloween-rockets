#Halloween rockets 

This game is a modification of my last week 3D sim(except it isnt 3D anymore)It is Halloween themed where u have to dodge the pumpkins to survive! I dont know why but i kinda juz got the idea randoomly in my mind. There is no VTVL capabillities as it is not a sim. The physics is simpler now.

##How to play

Go to the release and download the zip and unzip it. Run the .exe and make sure you have the other 2 assets in the zip.
Use the arrow keys for game play and also be sure to not exceed 45 degrees or it is a crash
press [P] for parachute
pres [r] to reset
press [space] or [enter] to launch
